\(\sqrt{ab}\) = 9.54  ≤  \(\dfrac{a+b}{2}\) = 10.00
拖动点 D：无论怎么移动，半弦 CD 都不会超过半径 OD。
课堂悬念 先猜后验
把 a 从 1 慢慢调到 10（点 C 移向圆心 O），半弦 CD 与半径 OD 的大小会怎样？
验证结论：直径 AB 固定为 20，所以半径 OD = 10 永远不变；而 CD 是 Rt△OCD 的一条直角边，OD 是斜边，直角边不可能超过斜边。只有当 C 与 O 重合（a = b = 10）时，△OCD 退化，CD 才与 OD 相等——这正是基本不等式取等号的几何真相。

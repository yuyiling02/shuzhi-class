课堂悬念 先猜后验
a = 1 固定，把 c 从 2 慢慢调到 −4，抛物线与 x 轴的交点会怎样变化？
验证结论：只改 c 时，a、b 不变，抛物线的形状与对称轴都不变，只是整体上下平移。判别式 Δ = b² − 4ac 随 c 连续变化：c 由 2 降到 −4 时 Δ 从 1 先减到 0（相切）再变成负数（无交点）。所以图象会经历"两个交点 → 相切 → 无交点"的过程，解集也随之改变。

数轴 · 有理数 3D 课堂七年级上册 · 第一章 有理数

教学模式

拖动 A、B 比较大小：数轴上右边的数总比左边大

实时数据

A = −4　　B = 6　　P = −4
A 的相反数：4　　B 的相反数：−6
|A| = 4　　|B| = 6（到原点的距离）
A ＜ B　B 在 A 右边

动点 P：从 A 出发，每秒 2 单位向右

运动时间 t = 0 秒
P = A + 2t = −4
AP = 0　　PB = 10　　AB = 10

课堂闯关 · 3 题

数轴上 A、B 表示 −4 和 6。动点 P 从 A 出发，以每秒 2 个单位的速度向右运动，运动时间为 t 秒。
第 1 题　用含 t 的式子表示 P 对应的数
第 2 题　P、B 相距 4 个单位时，t 是多少？
情况①　P 在 B 的左侧：PB = 6 − P = 4，即 −4 + 2t = 2，解得 t = 3。
情况②　P 越过 B：PB = P − 6 = 4，即 −4 + 2t = 10，解得 t = 7。
第 3 题　P 到原点的距离等于 2 时，t 是多少？
情况①　P 在原点左侧：P = −2，即 −4 + 2t = −2，解得 t = 1。
情况②　P 在原点右侧：P = 2，即 −4 + 2t = 2，解得 t = 3。
关键　“到原点的距离”就是绝对值：|P| = 2 → P = ±2，两个方向都要考虑，别只算右边！
📘 知识讲解 · 有理数（七年级上册）

一、正数与负数：表示相反意义的量

像 3、1.5、½ 这样大于 0 的数叫正数；
在正数前面加上“−”（负号）的数叫负数，如 −3、−0.5、−2/3。
正、负数用来表示相反意义的量：
　零上 5℃ 记作 +5℃　↔　零下 5℃ 记作 −5℃
　收入 200 元 记作 +200 元　↔　支出 200 元 记作 −200 元
　向东走 3 m 记作 +3 m　↔　向西走 3 m 记作 −3 m
注意：① “+3”与“3”是同一个数，正号可以省略；
② 一个数前加“−”，不一定是负数，如 −(−4) = 4 是正数；
③ 判断正负，看化简后的结果，不能只看有没有负号。

二、零：不偏不倚的分界线

0 既不是正数，也不是负数，它是正数与负数的分界。
0 是整数，也是有理数；0 的相反数是 0，|0| = 0。
0 既可以表示“没有”（如盘子里有 0 个苹果），
也可以表示一个具体的量：0℃ 不是没有温度，而是冰水混合物的温度；海拔 0 m 表示海平面。
课堂追问：气温 0℃ 和“没有温度”一样吗？海拔 0 m 处是不是没有高度？
—— 引导学生体会 0 的“基准”意义。

三、有理数：整数 + 分数

整数：正整数、0、负整数（… −2, −1, 0, 1, 2 …）
分数：正分数、负分数（½、−0.5、2/3 …）
有限小数和无限循环小数都可以化成分数，所以它们也是分数。
有理数的分类
有理数 ┬ 整数 ┬ 正整数
　　　 │　　　 ├ 0
　　　 │　　　 └ 负整数
　　　 └ 分数 ┬ 正分数
　　　　　　　 └ 负分数
一眼判断：能不能写成 p/q（p、q 是整数，q ≠ 0）？能写出来就是有理数。
每个有理数都能在数轴上找到自己的位置 —— 这正是我们画数轴的原因！
拓展一眼：π ≈ 3.14159…、√2 ≈ 1.414… 是无限不循环小数，叫无理数，
它们不能写成分数，所以不是有理数。
（“有理数 + 无理数 = 实数”要到七年级下册才正式学习，现在只需知道有理数的分类。）

四、数轴三要素：原点、正方向、单位长度

数轴三要素：原点、正方向（一般向右，画箭头）、单位长度，缺一不可。
画法：画直线 → 定原点 → 定正方向 → 取单位长度 → 标刻度、写数字。
原点表示 0，原点右边是正数，原点左边是负数。
重要结论：数轴上两点间的距离 = 右边点的数 − 左边点的数（结果一定 ≥ 0）。
这正是动点问题里 AP、PB 的算法来源。

五、相反数与绝对值

相反数：只有符号不同的两个数互为相反数。
a 的相反数是 −a；0 的相反数是 0；互为相反数的两个数和为 0。
几何意义：互为相反数的两个点关于原点对称，到原点的距离相等。
绝对值：数轴上表示数 a 的点到原点的距离，记作 |a|，|a| ≥ 0。
正数的绝对值是它本身；负数的绝对值是它的相反数；|0| = 0。
例：|−4| = 4，|6| = 6，|0| = 0。
易错：−(−4) = 4（化简符号）；|−4| = 4（求距离）——两者结果相同，但意义不同。

六、有理数的大小比较

① 正数 ＞ 0 ＞ 负数；
② 数轴上右边的数总比左边的大；
③ 两个负数比较，绝对值大的反而小（如 −7 ＜ −3）。
两个正数：绝对值大的大（3 ＞ 2）；
一正一负：正数 ＞ 负数；
与 0 比较：正数 ＞ 0，负数 ＜ 0。
课堂活动：把 A、B 拖到各种位置，让学生抢答“谁大谁小、为什么”。

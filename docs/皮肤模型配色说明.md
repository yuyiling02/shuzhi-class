# 皮肤模型（organ-skin）解剖学配色说明

> 对象文件：`public/models/organ-skin.glb`、`public/models/organ-skin-disassemblable.glb`
> （两个文件原本逐字节完全相同；原文件已备份为 `*.original.glb`）

## 一、模型结构勘查结论

`organ-skin.glb` 是 Draco 压缩的 glTF，包含 **7 个部件**（`part_0` ~ `part_6`），
每个部件一个独立材质（`part_N_mat`），没有任何顶点色。

解码几何 + 三角形光栅化渲染后，逐一确认各部件身份：

| 部件 | 几何特征 | 解剖身份 |
| --- | --- | --- |
| `part_0` | 底部厚板，蜂窝状气泡结构，占 y 0.00–0.43 | **皮下组织（脂肪层 / hypodermis）** |
| `part_1` | 中部最厚体块（19 万三角面），顶面呈波浪状凹陷 | **真皮层（dermis）** |
| `part_2` | 914 顶点的小分叶团块，位于真皮中下部、紧邻毛囊 | **腺体（皮脂腺 / 汗腺）** |
| `part_3` | 细长弯曲柱体，底部膨大成球，穿透表皮伸到皮肤外 | **毛发（毛干 + 毛球）** |
| `part_4` | 顶部盖板，底面有圆钝扇贝状凸起（真皮乳头），厚 0.67 | **表皮层（epidermis）** |
| `part_5` | 真皮内纵向细柱，从深层延伸至真皮顶部 | **毛囊（真皮内毛根鞘）** |
| `part_6` | 皮肤表面之上的细锥形柱体 | **毛干（露出皮肤部分）** |

层级关系（模型自身坐标，y 向上）：

```
y 1.52  ─┬─ 毛发露出部分（part_3 / part_6）
y 1.41  ─┼─ 皮肤表面 ─── 表皮层 part_4（0.74 – 1.41）
y 1.07  ─┤
         │   真皮层 part_1（0.31 – 1.07）+ 内部毛囊/腺体（part_2 / part_5）
y 0.74  ─┤   波浪状「真皮–表皮交界」（真皮乳头）
y 0.44  ─┼─ 皮下组织 part_0（0.00 – 0.43）
y 0.00  ─┘
```

> 说明：原始文件里 7 个材质的颜色全部挤在米黄/浅褐/棕这个很窄的区间内
> （如 `part_1_mat #E2BE8E` 与 `part_4_mat #E6BC8F` 几乎同色），
> 加上 glTF 的 `baseColorFactor` 是线性空间，实际渲染出来更偏灰白，
> 所以整体看上去是一整块「奶茶色」，各层无法区分。

## 二、配色依据

参考用户提供的 5 张切面图（皮肤1–5.png）并对照皮肤组织学资料
（表皮为角化复层扁平上皮；真皮为致密结缔组织，含胶原/弹性纤维、毛囊、汗腺、皮脂腺、血管与神经；
皮下组织为富含脂肪细胞的疏松结缔组织）：

| 观察到的结构 | 参考图中的颜色 |
| --- | --- |
| 皮肤表面角质层 | 浅奶米色 |
| 表皮层（波浪状下缘） | 偏饱和的肉粉 / 鲑鱼粉 |
| 真皮层 | 淡粉肉色（带纤维质感） |
| 皮下脂肪 | 明亮脂肪黄，蜂窝状 |
| 毛发 / 毛球 | 深棕近黑 |
| 毛囊壁 | 中棕（比毛干浅） |
| 皮脂腺 / 汗腺 | 淡象牙黄、分叶或盘曲团块 |

| 部件 | 材质名 | 解剖部位 | 颜色 | Hex | roughness |
| --- | --- | --- | --- | --- | --- |
| `part_4` | `part_4_mat` | 表皮层 | 浅奶肤色 | `#F3DCC0` | 0.85 |
| `part_1` | `part_1_mat` | 真皮层 | 玫瑰粉 | `#E3A494` | 0.80 |
| `part_0` | `part_0_mat` | 皮下脂肪层 | 脂肪黄 | `#EFD264` | 0.85 |
| `part_3` | `part_3_mat` | 毛发（毛干+毛球） | 深棕 | `#4A2B17` | 0.45 |
| `part_6` | `part_6_mat` | 毛干（露出部分） | 深棕 | `#402513` | 0.45 |
| `part_5` | `part_5_mat` | 毛囊 | 中棕 | `#8A5433` | 0.60 |
| `part_2` | `part_2_mat` | 腺体（皮脂腺/汗腺） | 淡象牙黄 | `#F4E7C4` | 0.75 |

所有材质 `metallicFactor = 0`，`doubleSided` 保持 `true`。

自上而下形成 **浅奶 → 玫瑰粉 → 脂肪黄** 三层主色带，
毛干/毛囊用不同深浅的棕色区分，腺体单独用淡象牙黄跳出来。

### 颜色空间注意

glTF 规范的 `baseColorFactor` 是**线性空间**数值。为了让最终渲染出来正好是上表的 sRGB 颜色，
写入时做了 sRGB → 线性转换（`c <= 0.04045 ? c/12.92 : ((c+0.055)/1.055)^2.4`）。

# 第二轮（v2）：统一毛发颜色 + 补上血管

> 需求：皮肤上的毛发颜色要统一；血管颜色也要有（参考 皮肤1–5.png）。

## 一、关键发现

1. **模型 UV 与原图集是对齐的**（第一轮误判为"贴图乱纹"，实为采样时多做了一次垂直翻转）。
   glTF 的 UV 原点在贴图**左上角**，即 `行 = v * S`，**不能翻转**。修正后渲染，
   表皮 / 真皮 / 脂肪层与图集内容完全对得上。
2. **7 个部件的 UV 岛互不重叠**（4096² 下重叠 texel 仅 2236 个，占 0.01%），
   图集覆盖率 61.4%。因此可以按部件安全地重绘图集。
3. **GLB 里本来就有一张内嵌图**（`images[0]`，2048² PNG，名字 `shaded`，5.08MB），
   但 7 个材质都没引用它——是遗留的孤儿资源。本次直接**替换它的数据**，
   不新增图片，文件反而更小（7.34MB → 4.68MB）。
4. 图集里的血管是**细线条**（脂肪细胞之间、真皮里的红/蓝细线），
   用固定色相阈值会把大片粉色组织误判成血管，必须用 **top-hat（原图 − 大半径模糊）** 做细线检测。

## 二、做法

| 步骤 | 说明 | 脚本 |
| --- | --- | --- |
| 1 | 各部件 UV 光栅化为图集掩码，验证不重叠 | `scripts/skin-uvmask.mjs` |
| 2 | 按部位平涂（保留低频明暗）+ top-hat 提取血管 → 动脉红/静脉蓝 + 开运算去噪 + 空隙平铺填充 | `scripts/skin-atlas-paint.py` |
| 3 | 替换 GLB 内嵌图，并把 7 个材质指向它 | `scripts/skin-atlas-to-glb.mjs` |

血管只作用于 **皮下脂肪 + 真皮**两个部件；**毛发（part_3 / part_6）强制纯平涂**，
保证颜色完全统一、不带杂色。

# 第三轮（v3）：血管改为连续条状脉络 + 毛发统一黑棕 + 表皮肉橘

## 一、关键结论：血管不能再从原图集里"提取"

上一版（v2）的血管是从原图集 `_lod_img0.jpg` 做 top-hat 细线检测提取的，
但**渲染到模型上是一堆点状碎斑**。原因不是阈值，而是模型本身：

- UV 极度碎片化：`part_0`（脂肪）在 3D 上有 4.7 万个连通分量，UV 岛极小。
  原图里连续的一条血管线，映射到模型表面必然被切成碎点。
- 阈值放松 → 糊满整张图；阈值收紧 → 更碎。**这条路走不通。**

## 二、v3 做法：在 3D 空间生成血管管网，再按顶点 UV 反写图集

```
scripts/skin-dump-verts.mjs    导出各部件顶点 [x,y,z,u,v] → scripts/_skin_verts/
scripts/skin-atlas-vessels.py  3D 生成管网 + 重绘图集（主力脚本）
scripts/skin-atlas-to-glb.mjs  图集写回 GLB
```

1. **3D 蛇形游走**：把 `part_0`（脂肪）+ `part_1`（真皮）顶点合并成点云，建 0.05 单位网格邻接表；
   从随机顶点出发，按"保持方向 + 随机扰动"逐步跳到附近顶点走出平滑蛇形路径，每步 5% 概率分叉。
   动脉:静脉 ≈ 55:45。
2. **栅格化血管场**：0.006 单位栅格，路径打上"芯（r=0.020）/ 外缘（r=0.031）"两层球体。
   必须**分两遍写**（先全部外缘、再全部芯），否则后一个采样点的外缘会抹掉前一个的芯。
3. **按顶点 UV 反写**：每个顶点查血管场取值 → 圆盘笔刷（r=2px）涂到其 UV 位置；芯最后覆盖，
   条带连续且有管状层次。
4. **细长部件补画**：腺体/毛发/毛囊/毛干的 UV 岛是极细长条，掩码点采样会漏掉大量 texel，
   漏掉的会被"填空"用邻近浅色覆盖 → 表现为**毛发发白**。对这 4 个部件额外用顶点圆盘笔刷
   （r=3px）直接补画，且写入后不再被填空覆盖。
5. **毛发统一**：`part_3` / `part_5` / `part_6` 全部 `#36200F`，并强制纯平涂（不做明暗调制）。

## 四、顺带修掉的两个 bug（只影响预览脚本）

- `skin-vessel-probe.mjs` 深度测试写反（`z >= depth` 保留的是**远处**），
  导致前面的毛发被后面表皮盖住，一度误判成"毛发颜色没生效"。
  已改为 `depth.fill(-Infinity)` + `z <= depth[k]`。
- `skin-atlas-vessels.py` 血管场栅格化顺序错误（见二.2）。
